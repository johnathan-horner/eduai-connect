Healthcare Decision support only
Medical Image Triage

Fine-tuned image model that scores chest X-rays, auto-triages confident cases and sends unsure ones to a human review queue. A Bedrock LLM writes a short summary from the model output only. Every result is labeled decision support only, not a diagnosis. Public research data; never used with patients.

PyTorch ResNet18 PneumoniaMNIST Amazon Bedrock Claude SQLite Streamlit Model Card CI/CD Audit Log
Measured
Test split: 92.1% accuracy, 99.5% pneumonia recall, 79.9% specificity
Routing
76.9% auto-triaged at 97.9% accuracy with no missed pneumonia; the rest go to a person
Guardrails
LLM sees only model numbers, template fallback, append-only audit log per case
Cost
Trained on a laptop CPU; about $0.0015 per LLM summary

Financial Services Synthetic data
Transaction Anomaly Detection

Flags unusual card transactions with an Isolation Forest model plus five plain rules, gives every flag a score and a plain-language reason, holds confident flags and sends lower-confidence ones to an analyst queue. Every score and decision goes to an audit log.

scikit-learn Isolation Forest FastMCP SQLite Streamlit MCP Server CI/CD Audit Log
Measured
Later test period: hold lane 95.4% precise, 81.1% of anomalies flagged overall
Design
Model and rules calibrated on validation and combined into one score
MCP
6 tools backed by the detector; no model calls; same request, same score
Data
328,448 synthetic transactions with labeled fraud patterns and hard negatives

Legal Document Type Classifier

Sorts legal documents into 8 types (contracts, court opinions, rules, notices, presidential documents) with a confidence score, sends low-confidence documents to review, and logs every decision.

scikit-learn TF-IDF Logistic Regression Federal Register API Streamlit CI/CD Audit Log

Routing

Data

Cost
